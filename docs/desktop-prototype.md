# Rust + GPUI Kit 桌面原型验收与测量

日期：2026-11-14。结论：本机已完成可运行的 macOS 原型、打包和测量，验证了轻量分发的可行性；未做与 Tauri/Electron 的同功能对照，不能据此宣称更快或更省内存。Windows/Linux 尚未构建、打包或真机验收。

## 实现范围

| 页面 | 已实现 | 限制 |
| --- | --- | --- |
| 安装管理 | 检测 harness 可执行文件；查询 Claude 用户级安装与启用状态；安装、更新内置插件，启用/禁用 | 目前只有 Claude 适配器；Codex/Gemini 只检测程序；更新使用内置 0.1.5，未接在线版本源 |
| 运行状态 | 导入 `/agent-safeguard-status` JSON，显示就绪、阻断、规则版本、最近事件和规则编号 | 手动快照，非实时；不查询聊天记录，不证明其他会话状态 |
| 规则管理 | 读取/编辑 JSON、原引擎校验、原子保存、上一版备份与回滚 | 需要外部 Node.js 22+；新会话生效，不热切换现有会话 |

原有 `src/core.js`、`hooks/register.js`、命令行安装器和规则脚本未修改。桌面关闭不影响已加载插件的检测；未新增防护范围声明。

## 构建与体积

- GPUI Kit 0.9.1，依赖由 Cargo.lock 固定；Rust 1.99.1，Release，thin LTO、单 codegen unit、strip。
- 测试宿主报告：macOS 27.2 / arm64。测试不记录设备名称、账号、序列号或实际网络地址。
- 安装包包含应用、内置插件/规则模板和第三方许可文件；不包含 Node.js，不要求用户安装 Cargo。
- 本地 ad-hoc 签名并通过 codesign 验证；未使用 Developer ID 签名和公证，不是正式分发版本。

`.app` 大小是实际文件长度合计，不是 APFS 物理分配或整个系统新增占用。首次启动字体/GPU 缓存及用户后续规则文件不包含在此数值中。规则编辑依赖的外部 Node 体积必须单独计入完整部署成本。

## 启动速度

20 次启动打包后的 Release 可执行文件，均使用虚构演示数据，无 harness 探测或网络请求；每次结束进程后重新启动。未清除 OS、字体或着色器缓存，不能称作冷启动。

| 指标 | 从父进程启动到首次渲染后回调 |
| --- | ---: |
| 本轮第一次观测 | 597.49 ms |
| p50 | 375.07 ms |
| p95 | 448.93 ms |
| 最小 / 最大 | 356.32 / 597.49 ms |

程序在首次 Render 中登记下一帧回调；父进程读取该回调输出时停止计时。该指标包含启动进程和界面初始化，但不等于屏幕实际呈现时间或第一次输入响应时间；不含 Finder、Gatekeeper 和首次环境扫描。20 个样本只反映本次机器状态，未控制其他软件负载。

默认窗口内容尺寸为 1100 × 800 逻辑像素；字体使用系统字体，未清理系统缓存。

## 内存与空闲状态

每页单独启动，等待 3 秒后，每秒采样一次，共 30 次。使用 `ps` 汇总应用和子进程 RSS。

| 页面 | RSS 中位数 | RSS 最大值 |
| --- | ---: | ---: |
| 安装管理 | 113.58 MiB | 114.16 MiB |
| 运行状态 | 113.39 MiB | 113.97 MiB |
| 规则管理 | 114.78 MiB | 114.94 MiB |

本次三个页面的 `ps %CPU` 样本中位数均为 0.0%；这只是采样精度下的 OS 指标，不能解释为零耗电。未测显存、WindowServer、能耗、最小化状态、长期事件流或规则校验时短暂启动的 Node 进程。共享页也可能在进程树求和时重复计数。

## 验证证据

- 47 项现有核心测试通过；21 项现有原生 Mods 测试通过。
- 5 项 Rust 后端测试通过：无效规则不得覆盖文件、规则回滚和 Unix 权限、状态解析与结束状态、演示模式不修改 harness、错误输出不泄露与命令超时。
- 隔离模拟 CLI：安装、更新保留规则、失败更新恢复源文件、隐藏原始错误、拒绝降级通过。
- 真实 Claude CLI 的临时 HOME/config/workspace：安装、列举、禁用、启用、更新通过。未修改正常用户安装。
- 实际 GPUI 窗口检查：三页导航、环境检测、中文文本展示、演示规则读取/保存、虚构阻断状态 JSON 导入通过。未将文字粘贴等同于完成中文 IME 候选输入验收。
- Cargo Release 构建、格式检查和 Git 空白检查通过。检测逻辑未变；没有新增实际模型请求路径的防护保证。
- ZIP 解压至仓库外的临时目录后，签名验证与应用首次渲染通过，确认运行不依赖源码工作目录。

安装失败时恢复的是应用部署的源文件；无法保证撤销 harness CLI 已经执行的所有配置更改。并发打开多个管理进程时没有跨进程锁，避免同时修改同一配置。
