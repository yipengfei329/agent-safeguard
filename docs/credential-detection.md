# 凭据检测

0.1.17 使用“字段上下文 + 具体值证据”，不再因字段叫 token/password 且字符串超过 4 字符就阻断。它是本地、有界的启发式检测器，不验证凭据是否真实有效，也不是完整语言解析器。

0.1.17 移除“无法识别的右侧表达式截取第一个词，再按秘密值评分”的兜底行为。仅在结构化实际字符串、引号字面值、已识别的透明包装、完整未加引号的配置/日志标量及显式认证格式中提取值。未知语法不能以标点和长度为依据触发凭据判断。

## 判断顺序

1. 私钥头、带密码的认证 URL、已支持的 Anthropic/GitHub/Slack Token 格式及 JWT 形状独立检查。这些显式认证证据不依赖通用熵阈值；例如认证 URL 中的短密码仍拦截。
2. 类型声明、代码引用、延迟变量替换、明确遮盖和常见占位符不构成具体秘密值。支持 Rust `pub`/`pub(crate)`、引用/生命周期/泛型、Swift/TypeScript/Python 等常见声明。仅排除当前表达式，类型后的初始化值、相邻字段继续检查。
3. 普通凭据字段必须同时有像秘密值的实际内容。`String`、`Bool`、`config.token`、`getSecret()`、`simulator`、`123456` 不再仅凭字段名阻断；结构化对象与文本使用同样证据标准。
4. 通用值采用长度、字符类别和 Shannon 熵组合，不对所有代码/哈希/随机字符串做全局熵拦截。密码字段达到 8 字符、3 类字符、熵 2.5；其他通用候选达到 12 字符、2 类字符（含数字或符号）、熵 3.0，或达到 24 字符、熵 3.5，才触发这条判断。还须先通过类型、引用、占位符等排除检查。熵只采样前 256 字符，每个字段的上下文工作有界。
5. JSON 里的凭据按解码后的值检查，避免转义引号增加长度和字符类别而产生误报。其他规则仍保留原始文本匹配语义；嵌套解码次数和扫描预算不变。
6. 支持常见透明值包装（Swift `.string`/`.some`、Some、String::from、SecretString::new、Buffer.from 等）及有界的直接字符串拼接。一般函数调用的参数可能只是环境变量名，不无差别视为密钥。

这意味着短密码、普通单词组成的弱密码，以及不符合已支持格式的短 Token 可能放行。这是本次“优先降低误报”的策略选择，不能宣称仍覆盖所有真实密码。需要强制保护的特定值可继续配置 `exact` 规则。

没有按测试文件、注释、`test`/`example` 路径或测试开关整段放行；测试代码旁边的高置信凭据仍然拦截。保留所有 IP、设备和其他自定义规则。

## 迭代与验证

规则启停、来源、工具范围和精确值通过 JSON 配置管理；值证据和语法识别属于引擎版本升级。公开测试只使用合成样本，不保存用户文件或会话内容。

- `tests/credential-confidence.test.mjs`：不同语言的声明、泛型、引用、JSON 转义、占位符、错误输出、模拟 Edit 全文件返回，以及相邻秘密值反例。
- `tests/credential-expressions.test.mjs`：未知表达式、Swift 值包装、不同输入来源与嵌套输出，并在每类放行样本后追加具体秘密值验证仍能阻断。
- `tests/credentials.test.ts`：原生插件返回/阻断和后续模型步骤，含密集 Rust 声明性能测试。
- `scripts/e2e.py`：隔离 HOME、虚构凭据、本地模型 API；确认正常结果产生第二次请求，阻断结果不提交后续请求。
- `credentialReason` 只返回原因分类，不返回命中原文；分类不等于确认凭据有效，也尚未接入桌面日志。

```sh
npm test
npm run test:mods
SAFEGUARD_TEST_INSTALLED=1 python3 scripts/e2e.py
```

## 生效与边界

已有会话持有旧引擎，必须重启或新建 Code 会话。升级保留用户规则，使用 `pluginVersion` 确认更新。工具结果拦截不撤销已经执行的编辑/命令，也不涵盖工具自己发出的网络请求。

100 ms 扫描预算、文本大小/深度限制和异常阻断不变。动态拼接、任意编码、陌生格式、无敏感字段上下文的密码和复杂/不完整语法仍可能漏检。不能通过本工具推断账号封禁原因。


0.1.17 验证（Claude Code 2.1.325）：1,746 项核心用例、67 项原生 Mods 测试、14 项桌面后端测试及 10 项双引擎验证用例通过。原生完整调用链、6 条启用规则、单并发，20 个预热后样本：100 KiB 密集 Rust 声明 p50/p95/p99 为 8/9/9 ms；1 MiB 为 62/64/65 ms。没有放宽原有 100 ms 检查预算。这些是本机样本，不保证所有输出或负载均低于预算：启用状态上报时，1 MiB、4 并发的完整调用路径 p50/p95/p99 为 137/169/197 ms，包含排队和上报开销。

0.1.17 的 66 项隔离端到端测试和 47 项安装版端到端请求测试通过：Rust 声明、Swift `.string(key)` 和未知表达式继续产生后续模型请求；`.string("高置信测试密钥")` 则只收到初始请求，未提交后续工具结果。仅使用本机模拟模型服务。实际误拦文件的私有回放也已放行，其内容不进入公开测试或报告。

未加引号的标量只接受受限字符集和明确值边界；复杂未加引号密码和未知函数中的普通字符串可能放行。明确 Token 格式仍在全文检查，自定义 exact 规则仍可保护指定值。该策略不能验证凭据是否有效。
