# 0.1.11 规则自测

所有样本均为合成数据；没有复制真实会话、私人规则或设备信息。测试预期根据规则含义编写，未用当前检测器自动生成预期。

## 覆盖范围

`tests/adversarial.test.mjs` 对 7 条示例规则逐项隔离验证：公网 IP、设备标识、主机名、凭据、精确文本、域名后缀及默认关闭的 CIDR。每条规则测试四个来源、八种包装形式、正常代码、相邻敏感值、规则关闭、观察模式、来源和工具范围。额外生成 512 组公私地址对，检查放行范围与混合输出。原有测试覆盖大小、深度、循环、类型声明、编码、图片默认放行与严格策略。

`tests/all-rules.test.ts` 对七条规则逐项执行真实 Mods 事件，验证图片/正常代码/敏感文本混合结果被扣留，并停止后续模型步骤。原有原生测试继续覆盖并发、异常输出、初始化失败和阻断状态。

`SAFEGUARD_TEST_INSTALLED=1 python3 scripts/e2e.py` 使用已安装插件、隔离 HOME、本地模拟模型 API 和虚构凭据，检查真实 Claude CLI 的请求次数。包含截图 Read、CSS grep 输出、身份字段声明、认证变量占位符、句尾 IP、实际身份值、数组 Token 和数字密码。

## 修复

- 主机名、设备字段共享有界赋值语法判断，允许明确的类型声明和变量引用，实际字符串仍检测。
- IPv4/IPv6 后的句号不再隐藏地址，域名末尾句号也能匹配，同时保留 CSS/标识符边界。
- Authorization 的明确变量占位符和认证前缀加变量表达式放行，实际认证值仍阻断。
- 数组元素继承敏感字段的含义，数字值也接受字段检测；布尔值、null 和普通嵌套对象不误当密码。
- MAC 地址支持冒号和连字符两种一致分隔符。

## 验证结果

- 1,283 项 Node 核心测试通过，其中包含参数化场景；这不等同于 1,283 种独立漏洞。
- 40 项原生插件测试通过，含全部七条规则的混合结果阻断。
- 32 个安装版 CLI 场景通过；正常输出继续到第二次模型请求，敏感输出停止在首次请求。
- 11 项 Rust 测试、10 组 Node/QuickJS 配置校验对照通过；安装版引擎与源码构建一致，个人规则文件摘要未变化。
- 原生插件分发耗时（6 条有效规则、单并发、20 个预热后样本）：100 KiB 普通文本 p50/p95 为 2/3 ms，密集代码 6/9 ms；1 MiB 普通文本 17/18 ms，密集代码 49/51 ms。不是所有机器或高负载条件下的延迟保证。
- 未实测的平台不能据此视为通过。

## 明确边界

规则不是任意语言的完整解析器。没有字段上下文的密码、任意混淆或动态字符串构造、尚未支持的 Token 格式仍可能漏检。四段纯数字版本号与 IPv4、六组十六进制字符串与 MAC 有语义歧义，目前保持保守检测。图片等二进制内容按用户策略放行，不检查图像内的信息。默认工具结果配置不扫描自动上下文；矩阵中的上下文测试验证能力，不表示本机已开启此来源。大型密集输出仍受 100 ms 协作式扫描预算约束。

新增误报必须补正常与敏感反例；禁止通过整个文件、整行或工具名称白名单消除误报。运行 `npm test`、`npm run test:mods` 和安装版端到端测试可重复本轮检查。
