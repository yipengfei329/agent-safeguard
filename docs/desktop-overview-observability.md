# 概览与观测验证（2026-11-15）

首页仅包含正在保护的会话和拦截历史。采集通过本机 Claude Code 2.1.325 生成的 Mods 类型声明核对，未引入第三方服务，也未改动 `src/core.js`、`src/credentials.js` 的检测语义。

## 可取得的信息

| 信息 | 来源与处理 |
| --- | --- |
| 宿主会话 ID | `$.session.id()`，启动后后台读取一次；`classic.SessionStart.session_id` 可同步补齐 |
| 项目 | `session.start.cwd`、`classic.SessionStart.cwd`、`classic.CwdChanged.new_cwd`；缺失时后台 `$.session.root()` |
| 会话标题 | `classic.SessionStart.session_title`、`classic.UserPromptSubmit.session_title`；宿主可选字段，未提供时显示未命名 |
| Agent / 模型 | 当前适配器 Claude Code；`agent_type`、`model`，缺失模型后台 `$.session.model()` |
| 拦截归属 | 命中时复制有界身份元数据；工具事件直接给出工具名和 agentId，子代理类型从 `classic.SubagentStart` 缓存 |
| 拦截原因 | 检测器返回的具体规则 ID；内置规则中文名称，自定义规则仅在当前版本匹配时解析本地显示名 |
| 诊断信息 | 插件版本、规则版本、最近报告时间、真实会话 ID 放入详情 |

不读取会话全文，不运行 Git 查询，不生成标题，不查询模型服务。项目名取路径最后一段，完整路径在详情。标题和路径可能包含私有信息，因此只保存在本机私有目录；不记录命中原文、工具参数或结果。

## 开销与可靠性

检测路径仅更新有界内存字段和脏标志，首次拦截通过零延迟定时器调度后台写入，不等待文件写入；已有写入在途则在成功完成后补写。后台 1 秒定时器合并变更、15 秒心跳，最多一次写入在途；单条报告限制 8 KiB。桌面每 2 秒后台轮询，按修改时间和长度缓存解析，UI 线程不读取报告文件。没有磁盘持久化服务，也不会要求 UI 在线。

每个插件实例锁定后只归档第一次拦截，后续拒绝与心跳不重复记日志。拦截历史独立保留最近 500 条，当前状态最多 100 个实例；桌面打开时清理超额且过期记录。突然退出或写入失败可能丢失未落盘历史，不能视为完整审计。45 秒无报告移出正在保护；未加载/被禁用的插件不会凭空产生记录。报告来自同一用户进程，不能防御伪造。

旧版报告仍可读取，但无法补出原本未采集的身份或事件时间。更新到包含本轮改动的插件 0.1.15 并新建会话后才有新字段。当前仅 Claude Code；未将后台子代理单独列为受保护会话，拦截归属可显示已取得的子代理类型。
