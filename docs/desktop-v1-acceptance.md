# 桌面一期验收记录

2026-11-14；桌面 0.2.0，内置插件 0.1.7。当前本机验收平台为 macOS arm64，Claude Code 2.1.325。

## 已实现

- 安装管理：自动探测、手动选择程序、安装与更新、启用/禁用、卸载确认；操作后重新查询宿主状态，保留本机规则。
- 概览：自动接收插件实例报告，展示规则版本、阻断与异常；心跳过期显示待确认，未加载不显示为受保护。
- 规则：内置规则开关、精确文本新增/编辑/删除、隐藏敏感值、草稿保存/放弃、上一版恢复、外部修改冲突检测；高级规则只读保留。
- Linear 风格原生界面：深灰背景与侧栏、紫色主操作、细分隔线、统一图标与紧凑规则列表。编辑器位于内容顶部，打开时定位并聚焦名称。原生窗口已检查概览、工具、规则和新增表单；本轮未通过真实用户配置进行保存测试。

检测算法 `src/core.js` 和 `src/credentials.js` 保持原样。桌面内嵌 QuickJS 执行同一引擎的配置编译，无外部 Node 运行依赖。插件适配层新增规则路径和异步最小状态报告；报告失败不改变检测结果。指定的桌面规则丢失时初始化失败，不静默切回默认规则。

原生 Mods 测试覆盖既有安全行为，以及状态报告不泄漏原文、报告写入失败不影响返回、指定规则缺失不回退。可使用 `npm run test:mods` 重跑。

完整流程使用临时 HOME / CLAUDE_CONFIG_DIR 和本机虚构模型服务。干净结果产生两次模型请求；保存精确匹配规则并启动新会话后，同一虚构结果被扣住，仅一次模型请求。报告不含该结果或自定义规则 ID。结果记录在 `desktop/artifacts/flow-results.json`，不推及其他宿主、插件禁用或未加载的请求路径。

现有 `strict-context-compatibility-block` 的干净兼容性探针在 Claude 2.1.325 上出现两次请求；未修改的 0.1.6 也相同。本轮将该干净探针允许的请求次数明确为 1 或 2，敏感上下文的原生阻断断言保留；不把这个探针当作所有上下文均可拦截的证明。

## 本机性能复测

Release app，隔离演示数据，20 次启动；每页稳定 3 秒后采样 30 秒。DMG 9.17 MiB，应用逻辑体积 23.79 MiB，ZIP 7.93 MiB。首次观测启动 871 ms，首帧回调 p50 370 ms、p95 670 ms；工具、概览、规则三页 RSS 中位数分别为 117.17、117.58、121.08 MiB。

性能方法与原始数值见 [本轮测量](desktop-v1-measurements.json)；历史数据仍保留在 [原型测量](desktop-prototype-measurements.json)。未清空系统缓存，启动测量是进程启动至首帧回调，不是冷启动或屏幕显示延迟；演示模式不包含真实宿主探测，RSS 不包括 WindowServer 和 GPU 分配。这些桌面指标也不代替完整检测拦截路径的延迟测量。
