# GeoIP 选型与隔离实测（2026-11-15）

推荐针对当前“CN / 其他已知地区 / 未知”需求，采用离线国家数据库、更新时合并相邻同类区间、会话初始化加载 Uint32Array、检测时二分查找。复用扫描器已有的 IP 解析结果，IPv4-mapped IPv6 归一化后查询。查询逻辑使用纯 JavaScript，兼容现有 Mods 运行环境；不新增常驻 Rust 服务、IPC 或逐次网络查询。

## 数据源

- DB-IP Country Lite：本轮使用 2026-11 版，732,796 条记录，IPv4/IPv6，月更、CSV/MMDB、CC BY 4.0。适合作为无需账号密钥的开源默认源。官方声明 Lite 的覆盖和准确性低于商业版，不能称其准确率最优。https://db-ip.com/db/download/ip-to-country-lite
- MaxMind GeoLite2/GeoIP：可作为可选源；下载涉及账号和许可密钥，许可/分发要求须按实际产品确认。https://support.maxmind.com/knowledge-base/articles/using-maxmind-license-keys
- IPinfo Lite：提供国家和 ASN，官方文档提供带 token 的下载地址，当前数据许可为 CC BY-SA 4.0。本轮没有账号数据，未作其全库性能或准确性实测。https://ipinfo.io/developers/ipinfo-lite-database

查询引擎与数据来源分离。这里选择 DB-IP 是部署和分发上的取舍；没有可靠的地理位置真值集，不能据查询速度推断哪个数据商更准确。

## 实测方法

下载 CSV 和 MMDB，解压后 MD5 与官网下载页一致，并另外记录 CSV SHA-256。TLS 校验证书开启。采用 mmdb-lib 3.0.5 读取完整 MMDB；轻量索引保留 CN、非 CN 的已知国家以及未知/未覆盖三态，不把“不在 CN 列表”直接解释为已确认国外。

重现资料位于项目忽略目录 `local/geoip-research/`：prepare.py、lookup.mjs、bench.mjs、boundaries.py、results.json、native-results.txt、native-repeat-1..3.txt。以上是选型阶段的隔离实验；随后 0.1.13 的生产接入和验证见下文。

- 数据文件：完整 CSV 32,485,911 B；完整 MMDB 8,515,063 B。
- 三态索引：IPv4 10,654 段、IPv6 9,330 段；JSON 864,224 B；Uint32Array 463,728 B。数组字节数不包含运行时、临时 JSON 对象和解析器的总内存。
- CSV SHA-256：5e968a64a29b973f794c5abc46d0711a0ba87c8a16c411e1cd70312db7a5d4e1。
- 12,000 个固定种子样本与 CSV、MMDB 结果一致；79,932 个首尾边界及相邻地址检查无差异。IPv4-mapped IPv6 应按 IPv4 语义处理，边界生成器排除其原始 IPv6 表语义，不冒充映射处理的全面验收。
- 以上仅证明同源转换和查表一致性，不证明真实国家归属正确。

## Node 测量

Node v26.10.0，预热后 100 批，毫秒。无结果缓存；同一批输入，包含 IPv4/IPv6 和边界样本。读取文件使用已下载的本地文件，OS 缓存未清除。

| 方案 | 100 个 IP p50 / p95 | 1,000 个 IP p50 / p95 |
| --- | ---: | ---: |
| 三态区间二分，含 IP 解析 | 0.157 / 0.200 | 1.530 / 2.214 |
| 完整 MMDB，含 IP 解析 | 0.693 / 0.958 | 7.521 / 9.827 |
| 二分，复用已解析数值 | 0.016 / 0.020 | 0.151 / 0.196 |
| 顺序检查 CN 区间，仅数值查询 | 2.120 / 4.680 | 31.386 / 39.991 |

顺序扫描基准只回答 CN 成员关系，不区分其他/未知；即使功能更少、无需 IP 解析，仍明显较慢，不适合直接扩充现有逐条 CIDR 比较路径。

Node 一次性初始化：JSON 转数值数组 p50 1.69 ms、p95 2.19 ms；含缓存文件读取约 1.79 / 2.18 ms。完整 MMDB 含缓存文件读取及 Reader 初始化约 1.09 / 2.02 ms。因此轻量索引在这项初始化微基准中并不更快，优势主要是查询和数据体积。

## 原生 Mods 测量

独立临时插件，真实原生 tool.call 分发，工具结果由测试桩提供。不是生产扫描器整合后的实际模型请求验收。30 个预热后样本；并发 1 / 4。为避免毫秒时钟精度造成误导，不把 0 ms 当作零开销。

复测三轮、单并发：

| 场景 | p50 | p95 范围 |
| --- | ---: | ---: |
| 100 个 IP，解析并查表 | 1 ms | 2–4 ms |
| 1,000 个 IP，解析并查表 | 6–7 ms | 6–10 ms |
| 100 个 IP，复用已解析地址 | <1 ms | 1 ms |
| 1,000 个 IP，复用已解析地址 | 2 ms | 3–4 ms |

相同大结果的无查询基线约 2 ms，表中是包含分发/结果传递的总时长，不能将分位数简单相减作为精确增量。四并发、每次 1,000 个地址的一轮复用解析结果测试 p50 8 ms、p95 9 ms；调度抖动使不同轮次有波动。

初始化：显式索引解析约 5–11 ms；原生 session.start 观察到 43–62 ms，早期首次测试曾为 232 ms。包含测试宿主和模块加载，不是受控系统冷启动测试。合并所有数据和样本为单个模块时触发了宿主 1 MiB 模块读取限制，拆分后通过；正式接入应使用独立数据资源并校验大小。

## 正式接入约束

1. 独立 GeoIP 索引，不将数万网段塞入当前线性 CIDR 列表；一次解析地址、去重后查表，有界缓存可选。
2. 初始化加载完整且校验过的索引，后续查询只读内存。数据库更新在检测链路之外执行。
3. 更新过程验证来源、摘要、地址族、排序、非重叠、状态值和样本一致性；原子替换，失败保留上版。当前原型加载函数不包含这些生产校验，因此不能直接当发布实现。
4. CN、其他已知地区、未知独立处理。数据库丢失/损坏也必须独立报告，不能静默标为非 CN。正常未知按用户选定策略处理。
5. 数据库携带来源、发布日期、许可署名和摘要。更新后新会话固定快照，避免在一次扫描中切换数据库。
6. 正式上线前增加真实安装版模型请求测试、损坏/缺失/更新失败测试和与完整扫描器合并后的性能测量。

本轮确认的是适合当前插件的查询方案；未启用 GeoIP 放行，当前公网 IP 拦截规则仍然有效。


## 0.1.13 生产接入

默认国家规则为 `mode: country, country: CN, onUnknown: allow`；内网豁免在查询前执行，其他国家及未知地址不触发 IP 规则，但继续检查其他规则。旧 any/cidr 模式仍可配置。国家信息不证明使用者位置，也不能由此推断账号封禁原因。

实际发布采用 uint32 小端编码再 Base64，数据约 604 KiB，与引擎合并后保持 Mods 单模块 1 MiB 限制内。无需新增安装资源路径。每个运行实例首次启用国家规则时校验并加载一次，后续编译复用。加载时验证版本、长度、校验和、区间顺序/重叠/边界及状态值。索引的 FNV-1a 校验用于发现损坏，不是来源认证；来源 CSV 使用 SHA-256 校验，月度更新由维护者显式执行。不能加载插件代码本身时，不能承诺插件有机会阻断。

更新示例（SHA-256 是解压后的 CSV）：

```sh
python3 scripts/update-geoip.py --csv-gz /path/to/dbip-country-lite-YYYY-MM.csv.gz --month YYYY-MM --sha256 <verified-decompressed-csv-sha256>
npm test
npm run test:mods
```

转换失败保留旧索引，成功时校验后原子替换，再构建、测试并发布。不自动修改已有用户配置；本次本机迁移只更新 `network.address` 的国家模式，保留其他规则、来源与私网豁免。

测试包括合成国家表的首尾边界、映射 IPv6、CN/其他/未知三态、损坏和缺失数据库、旧配置兼容、混合凭据以及全量发布索引的 39,968 个区间端点（映射空间例外）。历史所有 IP 拦截测试明确保留 any 模式，国家默认策略另有独立测试。原生及端到端国家命中样本取自公开数据库，不使用用户真实地址，不连接样本 IP。

原生 Mods 完整路径测量：6 个启用规则，含输入/输出检查及宿主调度；每组预热 5 轮、测量 30 轮。100 个 IP 约 2 KiB、1,000 个约 21 KiB。发布副本实测首次初始化约 68 ms（包括宿主调用，不是单独二分查询），属于会话启动的一次性成本。单并发 1 / 100 / 1,000 个 IP 的 p50 约 0 / 1 / 4 ms，p95 约 1 / 1 / 5 ms；4 并发、每份 1,000 个 IP 的 p50 / p95 / p99 约 16 / 18 / 18 ms。这不是所有设备的延迟保证，重复测量会波动。

真实 CLI 接本机模拟 Messages API：CN 结果仅有初始请求，没有携带工具结果的后续请求；其他/未知结果允许第二次请求。测试不访问真实模型服务。已运行会话保留旧引擎和旧规则，必须新建会话后验证版本与 `geoip` 状态。


发布副本验收结果：1,305 项 Node 测试、50 项原生 Mods 测试、2 项损坏数据库隔离测试、11 项桌面 Rust 测试、10 项 Node/桌面校验一致性用例；54 项隔离 CLI 端到端与 35 项本机已安装插件端到端全部通过。另验证安装/启停/更新、失败恢复及禁止降级。当前测量和 CLI 验证使用 Claude Code 2.1.325。故障复现命令为 `python3 scripts/test-geoip-failure.py`；已安装路径验证为 `SAFEGUARD_TEST_INSTALLED=1 python3 scripts/e2e.py`，后者仅在隔离配置中启用目标插件，不继承账号凭据。
